# Pruning não estruturado

A apresentação em PDF está no arquivo [pruning-nao-estruturado.pdf](pruning-nao-estruturado.pdf).

Na pasta [`html_com_lab`](html_com_lab/), está a versão interativa em HTML. Para acessá-la, baixe o projeto e abra `html_com_lab/index.html` no navegador.

Essa versão inclui um **laboratório com quatro experimentos**: escolher qual peso sai (magnitude × Wanda), desligar pesos, acompanhar o SparseGPT passo a passo e tentar chegar a 2× de velocidade pela Lei de Amdahl.
